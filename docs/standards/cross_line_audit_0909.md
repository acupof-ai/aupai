# 跨线人工抽检协议（0909）

## 为什么横向

每条线自己抽检自己等于自己判自己的卷子。统一协议、跨线读者，才比得出哪条线更差。全合成路线下（用户 09-09 裁定：1.3B/30B，约 20B 合成教科书 + 6B 过滤代码），训练集 2/3 以上没有外部来源可对照，人工抽检是它唯一的外部验证。

## 四条线与判定问题

| 线 | 线主 | 判什么 |
|---|---|---|
| 合成教科书 | b0 | 是不是教学材料（不是"像不像代码"）；同主题两篇是否换皮重复 |
| 合成练习 | 44 | docstring 与 solution 是否一致、题目是否有意义；同主题两篇是否换皮重复 |
| 分类器输出 | e1 | 同一把质量尺子打高/低两组——分类器唯一的外部验证 |
| 去污染剔除 | 3b | 被剔除样本里多少是误伤（本可保留） |

判定三档：keep / cut / undecidable。undecidable 是第三档，不折进任何一边，不丢分母（handread_criterion_0908）。换皮判定二档：reskin / not，按对记。

## 抽样（四条线共用 scripts/audit_sample.py）

- 合成教科书：按 3b 的 20K 主题种子分层，随机 25 主题 × 每主题随机 2 篇 = 50。全局随机 50 测不到主题塌陷——那是分布问题不是样本质量问题（fb 09-09）。教科书产物必须带主题种子 id，否则抽样器无法分层。
- 合成练习：同样分层成对。自我重复是合成数据的同一种病，单篇上看不出来，必须成对给读者看。
- 分类器：高分组随机 50 + 低分组随机 50（共 100），读者不见组标签，标签在标注后 join。
- 去污染：剔除样本随机 50。
- 随机用 `random.Random(seed).sample(sorted(ids), n)`，seed 写死 20260909；取样器断言样本不等于语料头部（handread_criterion_0908 的教训：`rng.shuffle` 一个被丢弃的列表是空操作，样本曾是前 40 条）。
- 样本带源指纹（每个源文件 sha256）；源变了取样器拒绝覆盖旧样本（.srcfp 规则）。
- 读者只见文档文本，不见线名、分组、分数。

## 读者与一致率

- 两个读者独立标同一份，线主不读自己的线。
- 记一致率 + Cohen's κ（文献中位 0.60，data_quality_methods §4）。
- 分歧样本逐条列出，不平均掉。
- 读者从 roster 固定配对出（提议，fb 裁定）：

| 线 | 读者 | 出处 |
|---|---|---|
| b0 教科书 | tilerl, 3b | tilerl↔b0、3b→b0 减去 b0 |
| 44 练习 | de, fb | de↔44、fb→44 减去 44 |
| e1 分类器 | 3b, b0 | e1→3b 减去 e1，补 b0 |
| 3b 去污染 | b0, e1 | 3b→b0 减去 3b，补 e1 |

## 判定规则（读前固定）

- keep 率 ≥ 80% → 可进 mix。
- 60–80% → 线主修完指名失败模式后复抽 50 重审。
- < 60% → 不进 mix。
- 换皮率单独报：它是生成侧的病，高了在生成端去重或砍该主题层，不折进 keep 率。
- 80% 沿用 handread_criterion_0908 的 0.80（aupai-6e 阈值）。

## 分辨率（读前写明）

n=50 二项 95% 半宽约 ±14pp（p=0.5 最宽）。这张表排得了四条线的量级，排不了 70% 和 80%。要 ±5pp 得 369 篇（facts/data_quality.json#dq.sample.size_table）。分类器线 n=100，半宽约 ±10pp。
