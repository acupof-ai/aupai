# mix_200m_4b 9 域 hand-read 审计

## 结论

**配比不是拿分的瓶颈，token 量是。** 手读只能说"数据形态与 benchmark 相关度高/中/低"，不能说"可拿非零分"：分数由 token 量决定，200M@4B 的 base 在生成类上为 0（generative_zero），非零要经 SFT。cot 域（~85% 可用、清一色数学/几何/组合/微积分题解带步骤）与 code 两域（真实 Python）提供了与 GSM8K、HumanEval 同形态的实质内容，形态相关度最高；math_owm 提供半干净数学问答补充。但高分受稀释与错位限制（math_owm 50% 平台脚手架噪声、code 多工程样板非单函数题带测试、textbook/chat_qa/zh_web/cot 多中文或合成、en_c4 大量广告低质）：若以这些 benchmark 为指标，配比需按域损益调整（加权 cot 与 code 干净子域，抑制 en_c4/zh_web）。
