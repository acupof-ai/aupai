## Filter rules for e1

Rules ordered by impact (fraction of sample they would remove):

1. **HTML docs** (dd09 10%, b2 8%): starts with `<!DOCTYPE` or `<html` or contains `javadoc`/`doxygen`/`LCOV` generator meta. Removes Javadoc/Doxygen/LCOV/MSDN noise.
2. **Auto-generated code** (dd09 4%, b2 4%): header contains `auto-generated`, `Generated by`, `do not modify`, `@generated`, `WSDL2Java`, `Propel`. Removes ORM/WSDL/FlatBuffers stubs.
3. **CSS files** (dd09 2%, b2 0%): content is predominantly CSS selectors (`.class {`, `#id {`, `@media`).
4. **License-only files** (dd09 4%, b2 0%): <500 chars, contains `Licensed under`/`Copyright` and no functional code.
5. **Empty/trivial class bodies** (dd09 2%, b2 2%): AST-detectable — class with no methods or only `pass`/empty body.
6. **Config files** (dd09 4%, b2 4%): Maven POM XML, Dockerfile, Homebrew cask, setup.py — detectable by filename or root-level XML/YAML with no executable code.

Combined removal if all rules applied: ~22% dd09, ~14% b2 — the non-code tail. Boilerplate that is syntactically code (empty classes, stubs) is lower-value but not harmful; rules 4–5 are optional.

## Sampling

- Method: stratified random, seed=42, n=50/corpus, max 2 docs/shard, shard weights proportional to doc count.
- dd09: 235 shards, 3,434,322 docs (post-dedup, 8.3% deleted by MinHash-J char 5-gram threshold 0.9).
- b2: 152 shards, 2,423,371 docs (pre-dedup).
- Content truncated to 500 chars for hand-read; full content lengths recorded (range 144–122,446 chars).
- Limitations: n=50 gives ±14% half-width at p=0.5 (95% CI); per-category rates are noisier. 500-char truncation may hide tail defects in long docs.
