## Still open

Each is a constant offset rather than a wrong comparison, which is why none has been
fixed: they move a number without changing which checkpoint wins.

- **`eval/hellaswag.py:19` and `eval/winogrande.py`** tokenize context and continuation
  separately. This tokenizer sets `add_prefix_space: false`, so the word separator is
  deleted and the option's first token differs from what the model saw in training.
  Two of nine non-math benchmarks. `piqa.py` and `arc.py` do it correctly.
- **`eval/math_zh.py:37`** returns 0.0 when the *gold* carries no `\boxed{}`, charging
  unscoreable references to the model. 1.476% of the source corpus lacks `\boxed`,
  so roughly 7 of the 500 holdout rows are unwinnable.
- **`scripts/plot_curves.py:70`** pins the last validation point to the right edge by
  dividing by `max(step)`. The denominator has to come from `total_steps`, which
  `parse()` currently discards, or an interrupted run still plots wrong.
