# 复制假设：语料侧的三次测量

**结论先行，两句话，缺一句都会误导：**

> **语料里没有重复，而且我们也没有留出测量。两句都要说。**

第一句是这次测出来的；第二句是测的过程中掉出来的，它比第一句要紧，因为它
决定了第一句能被用来支持什么。

## 1. 先说那个注释

`eval/domain_loss.py:47` 取 `sorted(files)[0]`，注释写着
**"the head, matching train.py's val split"**。这句话是错的。

train.py 的顺序是：把域内文档 `random.Random(_sample_seed()).shuffle`
（:1560），**然后**切 `val = seqs[:n_val]`（:1751）。洗牌夹在两者中间，所以
"按文件名排序的第一个 shard"的头部会被均匀打散到整个池子里，注释断言的那个
对应关系不存在。

在 cot 上按文档下标复现这次洗牌（`probes/t64_val_head_overlap.py@381d922`，不需要
tokenizer 也不需要 GPU）：

| 量 | 数 | 占被打分的 4000 篇 |
|---|---|---|
| 落在 val 切片里 | 198 | **4.95%** |
| 落在训练池里 | 3802 | **95.05%** |

**所以我们一直在读的 per-role 数字里，约 95% 是训练损失。** 不是被污染的
留出损失——是训练损失，本来就是。

这一条排在最前面，因为它改变后面两节的读法：**一个没有留出集的对比，测不出
记忆化，无论语料多干净。**

## 2. 重复：四个域，文档级 0.000–0.010%，行级全零

按 `_domain_seqs` 实际喂给 tokenizer 的字节扫描（不是抽样，是全量消费行）：

| 域 | 文档级精确重复 | 行级 | 备注 |
|---|---|---|---|
| math_owm_stage2 | 0.000% | 0（1,173,995 消费行）| 近似重复 0/2000 抽样对 |
| 其余三域 | 0.000–0.010% | 0 | 同上 |

**注意这个结果的方向。** 三个**从未做过去重**的域回来得最干净——而那正是
当初担心的三个。这是一个**结果**，不是一次松口气：它说明担心指向的机制
（去重缺席 → 重复堆积）在这批语料上没有发生，而不是说明我们的担心多余。
两者的下一步不同：前者结案，后者会让人把"没去重"当成安全的默认。

一次自查要记在这里：**第一版近似重复抽了 2.4M 消费行里的 2000 行 = 0.08%，
near=0 是抽样率而不是语料。** 自己抓到，重跑成对每一条消费行建索引。一个
空结果在发表前必须先证明工具会响。

## 3. 样板率：code_rp1t 至少 7.49%，en_c4 0.16%

fb 把这一项从"污染"重新框成"语料质量"，框对了——它测的不是训练/验证泄漏，
是这个域里有多少 token 是模板。

| 域 | 出现在 ≥3 篇文档中的 n-gram 覆盖的 token 占比 |
|---|---|
| code_rp1t | **至少 7.49%** |
| en_c4 | 0.16% |

同一把尺子，**47 倍**。参数（44 需要它们做对照，已发）：12-word n-gram、
whitespace 切分、小写、文档频次 DF ≥ 3、按文档 0.53% 均匀抽样。

**"至少"是承重的，不是谦辞。** 0.53% 的文档抽样只有在某个 n-gram 的 ≥3 个
实例同时落进样本里才看得见它，每一次漏掉都是假阴性，永远不会是假阳性。
所以这个估计是**单侧向下**的。不要写成"7.49%"。

**形状比这个数更可操作**：中位数文档是 0.00%，但 6.7% 的文档 >50% 是复现
文本。质量集中在少数文档（生成的、vendored 的、模板文件），所以便宜的动作是
**丢掉 6.7% 的文档**，而不是做一遍 span 级去重——少一个数量级的机械。

先在 5 个已知答案的例子上验证过，包括**一篇文档内部的循环得分 0.0**——用的
是文档频次不是原始频次，这正是会把数字吹起来的那个失效模式。

## 4. 这三次测量合起来支持什么

**支持**：复制假设的"语料重复"这一条腿，在这四个域上没有证据。

**不支持**："模型没有记忆化"。第 1 节说明我们手上没有留出读数，所以这个
问题今天**测不了**，与语料干不干净无关。

**也不支持**："样板率解释了 ppl 2.20"。fb 已裁定这一项不测，本文不推测。

fb 的措辞是准的，照抄：**这不是"驳倒"，是"没有重复，而且也没有留出测量"。**
把它写成驳倒，就是拿第一句去回答只有第二句能回答的问题。

## 5. 可复用的形状

**一、一个空结果的第一嫌疑是仪器。** 近似重复的 0 第一次是抽样率造的。守卫的
交付标准是"证明它会失效"，空结果的交付标准是同一条。

**二、注释是散文，散文会比测量断言得更多。** `domain_loss.py:47` 的注释断言
了一个洗牌之后不存在的对应关系，而它读起来完全可信。下一个读者拿走的是散文。

**三、担心指向的机制没发生 ≠ 担心是多余的。** 三个未去重的域最干净，这是
结果不是宽慰；把它读成宽慰，下一次"没去重"就会被当成安全默认。

## 6. 作废条件

- **有了真正的留出读数**：第 1 节的 95% 失效，per-role 数字第一次可以回答
  记忆化问题。
- **语料重建**：第 2、3 节的数只属于被扫的那批字节，重建即作废。
- **抽样率提高**：第 3 节的 7.49% 下界会上移，方向已知，幅度未知。
