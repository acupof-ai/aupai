# 成对评委协议(pairwise judge protocol)

RL 阶段 4(b) 的奖励来源。用户裁定不做训练奖励模型,所以**没有测试的任务上,评委就是唯一奖励**;一个没量过的评委是模型会去钻的奖励。本协议在 20 个有测试的任务上验收,验收不过就不用。

## 1. 评委 rubric(27B 的 prompt 规格)

**评委只做组内平局打破**:同一任务 K 条 rollout,测试先判——全过或全败的子组内才问评委;有测试差异的对不问评委,有测试时永不 judge-only(sandbox_env_survey §C 组成)。

输入:任务陈述 + rollout A + rollout B(各含代码与运行结果摘要)。评委**看不到**单元测试结果——测试是验收用的 ground truth,不是评委的输入;评委若能看到测试,在无测试任务上的行为就不可外推。

判据,按优先级:

1. **正确性**:代码是否完成任务要求。能跑、输出对 > 能跑、输出错 > 不能跑。
2. **质量**(正确性持平时):边界情况处理、无崩溃、可读。

输出:`A` / `B` / `tie`,外加一句理由(理由不进奖励,只供人审)。

## 1b. 准入:评委必须与策略不同模型族

策略是 27B Qwen 时,27B 自己不能当评委(自偏好,sandbox_env_survey §C:verbosity/self-preference 的缓解是 judge from another model family)。27B 试点先 tests-only,等有跨族评委再开 4(b)。策略是 500M 时,27B 合格(更强且异族)。评委冻结,不随训练更新。

## 2. 位置交换去偏

每对 rollout 判两次:一次 (A,B) 序,一次 (B,A) 序,同 rubric、同温度 0。

- 两次结论一致 → 该结论成立。
- 两次结论不一致(含一次 tie 一次非 tie)→ **弃权**:该对不发奖励信号。
- 两次都 tie → tie 成立。

位置偏置是 LLM 评委的已知失效模式;交换不一致是评委对这对 rollout 没有可靠区分度,弃权比硬选诚实。

## 3. 平局处理

- 两次都 tie → 两 rollout 同分(GRPO 里两者奖励相同,优势为零)。
- tie 只在正确性与质量都不可分时使用;评委 prompt 里写明「有疑问就选一边,不要用 tie 回避判断」——tie 率本身是评委质量指标,过高说明 rubric 不够区分。

## 4. 验收测试(20 个双任务)

20 个任务同时有:(a) 单元测试结果,(b) 同一子组内(全过或全败)的一对 rollout,(c) 评委的两次判定。评委只在这种子组对内被验收——有测试差异的对本来就不问评委。

- **一致率** = 评委结论与测试顺序一致的对数 ÷(一致 + 不一致);弃权对不计入分母,单独报弃权率。
- 验收线:**一致率 ≥ 0.8**;低于则评委不用,阶段 4(b) 奖励回退到「有测试用测试、无测试不发信号」。
- 弃权率与 tie 率随一致率同行报告;一个 0.9 一致但 0.6 弃权的评委等于只在 40% 的任务上发信号,必须显式读出来。
- 正面对标 Rubric Dropout(2608.11669):训练评委分升而金标降 22 pt——0.8 门和「不过不用」就是防这个;首次实测在 0.7-0.8 之间报「不可用」,不调线。

## 5. 评分器

`eval/pairwise_judge.py`(只依赖标准库)消费评委输出,产出每对判定与验收报告。tilerl 把它接在 tileRL API 后面:27B 两次判定 → JSONL → 评分器。

输入 JSONL,每行一对:

```json
{"pair_id": "task01", "order_ab": "A", "order_ba": "B", "test_winner": "A"}
```

`test_winner` 为 `null` 表示该任务无测试(发奖励但不进验收)。`order_ab`/`order_ba` 取值 `A`/`B`/`tie`。

输出:每对判定(A/B/tie/abstain)+ 验收报告(一致率、弃权率、tie 率、n)。

## 6. 参考文献(sandbox_env_survey §C,2026-09-02 fetch 核验)

- J1(2505.10320):双序一致,奖励一致性——本协议 §2 的直接依据。
- RULER(openpipe.ai/blog/ruler):一次调用给整组 N 条 rollout 排序,GRPO 下只有相对分重要;K>2 时的替代方案,本协议先做 K=2 成对。
- ArenaRL(2601.06487):种子锦标赛,O(N) 评委调用;非传递性的解法之一。
- 位置偏差在 rubric 下仍在(2602.02219)——§2 双序去偏的依据。
- Rubric Dropout(2608.11669):训练评委分升、金标降 22 pt——§4 验收门的依据。
