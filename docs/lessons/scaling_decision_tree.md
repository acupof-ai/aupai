# Scaling 决策树(预注册,看到数之前冻结)

拟合协议(v1.2)冻结了"怎么拟";这份文件冻结"**拟出来之后按什么决定下一步**"。
冻结规则相同:第一个点跑完之后不许改,只许发新版并说明。

**版本**:v1.8(2026-08-30)——新增 §8 表达能力阶梯读法(用户新方向,3.24b 落盘前写死)。v1.7 同日。

**目标不是曲线本身,是一个能用的 200M 中文模型。** 曲线是工具,决策是产物。

## 0. 输入

- 拟合输出:E(+ profile 95% 区间)、B、β(+ 区间)、verdict(ACCEPT/WEAK/FAIL)、残差形态
- D_max = 3.24B 点的面板读数:分域 NLL、最小对、LAMBADA-zh、math v2 似然孪生、ceval
- **E2 分域斜率**(44,六 checkpoint 分域 loss,共享曲线 RMSE 1.04 nat = 种子噪声 20×,模式为真):
  各域 loss 随 token 的斜率排序(web_hq −0.123 最平、textbook/en −0.26 最陡)+ 每斜率的 SE
- known-answer 校准(92.5pt / 85.4pt,runner 能读信号——已验)

## 1. 三个机械读数(从曲线直接算,不涉及判断)

1. **倍增收益** Δ_double = L(D_max) − L(2·D_max) = (L(D_max) − E)·(1 − 2^(−β))。
   下一个数据倍增能买多少 nat。
2. **剩余空间** R = L(D_max) − E。D_max 离这条曲线的渐近线还有多远。
3. **识别水位**(面板读数,非曲线):math 孪生、最小对、LAMBADA 在 D_max 的值。

噪声锚点:run-to-run ≈ 0.05 nat(Kaplan,ds.kaplan_noise;我们无内部重复,最弱锚点)。

## 2. 决策树

```
拟合 verdict?
├── FAIL / 否证形态命中 → §5(拟合失败分支),不从曲线做决策
└── ACCEPT / WEAK →
    ├── 改配比触发(§2a)→ 【改配比】优先于扩 D(零新语料,一个 json):
    │   ├── Δ_double < 0.05 → 扩 D 已死,改配比是数据侧唯一有可测收益的动作,直接做
    │   └── Δ_double ≥ 0.05 → 改配比先行(免费),用结果校准 E2 斜率对再分配的预测力,
    │                          校准后回主树重判扩 D
    ├── Δ_double ≥ 0.05 且 R > 0.10 → 【扩 D】下一倍增可测且有空间,跑 6.5B 点
    ├── R < 0.05 → 数据缩放到头 → 看识别水位:
    │   ├── 识别在(§3a)→ 【SFT 先行】知识有、产出无;SFT 便宜,先试产出
    │   │   ├── SFT 后生成式动了 → 天花板是产出,继续 SFT 路线
    │   │   └── SFT 后生成式仍零 → 天花板是容量 → 【扩 N】新阶梯
    │   └── 识别不在(§3b)→ 【换数据配方】知识不在模型里,加数据/加参数都不解决
    └── 中间态(Δ_double < 0.05 但 R > 0.10,或反之)且改配比未触发 → 报 fb,不自行决策
```

## 2a. 改配比分支(看到数之前写死)

**为什么它是第四条出路**:扩 D / SFT / 换配方都要新东西(新语料、新训练、新数据设计);
改配比只改一个 mix json,同 D 重跑,是唯一零边际成本的数据侧动作。
E2 给出的候选:web_hq 权重 32.4%(最大域)、斜率最平(−0.123 vs textbook/en −0.26)、
loss 最高(+1.50 在共享曲线上方)。

**触发条件(三条全满足才触发,机械读数)**:
1. E2 域斜率极差 max−min > 2×SE(44 的域拟合给 SE;模式为真的前提——
   共享曲线 RMSE 1.04 = 种子噪声 20× 已证,这里要求的是**逐斜率**可分辨)。
2. 最平斜率域的权重 ≥ 10%(从 1% 的小域挪权重挪不动聚合 loss;web_hq 32.4% 满足)。
3. **反触发(只有这条时不许改配比)**:各域斜率相同、只有 offset 不同 →
   offset 是内在熵/天花板,不是浪费(fb 对 E2 的收窄解读:web 文本干净时也该长这样)。
   只凭 offset 动配比 = 把熵当垃圾删,禁止。

**动作(触发后)**:从最平斜率域向最陡斜率域挪权重,**幅度 ≤10pt**,其余冻结。
10pt 封顶的理由:E2 的斜率是在当前配比附近测的,线性外推超过这个幅度未验证——
超了就是另一个实验,不是这一支。

**读法(改配比 run 本身是实验,预注册)**:D_max 同 token 数,新旧 mix 各一个 checkpoint,
其余全部相同。聚合 val NLL 改善 > 0.05(噪声锚点)= 成功,杠杆成立;
改善 ≤ 0.05 = E2 斜率对再分配**无预测力**,杠杆作废,扩 D 决策只看 β,不再引用 E2 斜率。

**识别限制(结果必须连同这句一起报)**:E2 设计里六个 checkpoint 同配比、
各域 token 共变(一起 ×16),域斜率是**排序观测**,不是"少给 web_hq 一万 token 会怎样"的
因果边际——反事实在该设计里不可识别。改配比 run 才是那个实验;
这一支的裁决是"值得做这个免费实验",不是"配比一定是错的"。

**陡极单源(v1.6,看到数之前标注)**:最陡的两个域 textbook/en(同 −0.26)同源于
chinese-cosmopedia(en 域 85% 是中文 cosmopedia,fb 实测 mlm.corpus.en_domain_is_mostly_chinese)——
斜率极差的"陡端"是一个源的两次计数,不是两个独立证据。平端(web_hq)不受影响,
触发条件 1 的机械读法不变;但改配比 run 的**方向论证**("从最平挪向最陡")实际是
"web_hq → cosmopedia",若 run 为正,收益归因到 cosmopedia 这个源,不归到"textbook 或 en"。

## 3. 识别水位的判据(看到数之前写死)

**(a) 识别在**——知识以潜在形式存在,缺的是产出:
- math 孪生 > 0.75 且 最小对 > 0.75 且 LAMBADA top-1 > 0.30
- 同时 math-500 pass@1 < 0.02(生成式在地板)
- 锚点:known-answer spread 92.5pt 证明 runner 可读;0.75 = "四分之三的对错解分得清";
  LAMBADA 0.30 ≈ 旧架构 3.24b 的实测 0.356(be.lambada_zh_heldout_3p24b,旧架构仅作校准)

**(b) 识别不在**——知识本身缺失:
- math 孪生 < 0.60(贴 50% 地板)或 最小对 < 0.60
- 解读:模型连"认"都不认,问题在数据配方或架构,不在模型大小

**(c) 评测盲**:由构造排除——known-answer 闸(≥60pt spread)证明 runner 能读信号。
新架构上某 runner 的 spread 塌了 = 该 runner 瞎,按面板规则砍,不解读成能力。

**(d) 阈值的架构迁移(看到数之前写死)**:§3a 的四个绝对阈值(0.75/0.75/0.30/0.02)
锚在旧架构(0830v1,已作废)的实测上——孪生 0.949、LAMBADA 0.356、pass@1 2.8%/0%。
新架构读数可能整体偏移。预注册规则:

1. 这四个阈值的本质是**绝对主张**(孪生 0.75 = "对错解 3:1 分得清"),不是相对 checkpoint 的;
   旧架构实测只是"200M 上可达"的可行性证据,不是阈值的定义。
2. 六个点跑完后、读 Dmax 分支之前,在新架构最强 checkpoint 上重跑三项 known-answer
   (孪生、最小对、LAMBADA)。
3. 某指标 spread <60pt → 该指标按面板规则砍,分支用其余指标判定。
4. 某指标新架构最强读数 **低于其绝对阈值**(阈值不可达)→ 按"已演示量程占比"下调:
   二选一指标 threshold = 0.5 + 0.557·(ceiling_new − 0.5),其中 0.557 = 旧架构 0.75 在其
   量程中的位置((0.75−0.5)/(0.949−0.5));LAMBADA threshold = 0.843·ceiling_new
   (0.843 = 0.30/0.356);pass@1 保持绝对 0.02(两架构地板都 ≈0)。
   下调必须连同"分支被削弱"一起报——阈值可达性修复,不是重定义。
5. 新架构读数 ≥ 绝对阈值 → 绝对阈值原样成立,不做任何迁移。
6. 重校准后的数字在读 Dmax 分支**之前**冻结,新旧对照写进报告。

## 4. 固定 N 的"最优点"怎么读(fb 的 Q1)

Chinchilla 的最优是给定 FLOP 下 (N, D) 的联合配比;**我们的 N 被部署约束钉死在 200M,
是"给定模型大小该喂多少 token",不是同一个问题。** 答案分两层:

1. **曲线能直接给的**:D* = 使 L(D) ≤ E + 0.05 的最小 D(进入噪声带)。
   D_max < D* → 还没喂够;D_max ≥ D* → 喂到了噪声极限,再加数据不产生可测收益。
2. **曲线给不了的**:D* 之后要不要继续,取决于替代干预的收益对比(§2 的 SFT/扩 N/换配方)。
   曲线只估值"更多数据"这一个选项;决策树把它和其他选项放在同一把尺上。

**E 的用途**:E 是"这个架构 + 这个数据配方在 200M 上的损失地板"。
R = L(D_max) − E 是唯一可行动的量(剩余空间);E 的绝对值是描述性的——
跨架构比较 E 需要同一 val 集上的更大 N,六个点给不了,不假装能给。

### §4 补充:语料质量已知偏低时 E/R 怎么读(v1.3,看到数之前写死)

背景:**web_hq = 全部 web 分片,未经质量切**——`data/corpus/web/` 已不存在,所有 shard
并入 web_hq(fb 2026-08-30 更正:不是"取前 N 片",web_hq 就是 web 的全部;
top-40 质量头切从未在这一版执行,那刀的收益从未被测过)。六个点跑在比原声明更脏的语料上。解读规则:

1. **E 是"这份语料的地板",不是"模型的天花板"。** 禁止把 E 与外部曲线
   (Chinchilla 1.69 等)直接比较——语料质量是未控变量。跨架构比较 E 本就需要
   更大 N(§4 正文),现在再加一层:需要同质量语料。
2. **R 对加性熵免疫。** 若脏语料只给每点加一个常数熵(可预测性整体下降),
   L(D_max) 和 E 同时抬高,R 不变——"这份语料上还剩多少可学信号"不受影响。
   **真正的误触发风险在非加性情形**:噪声 token 让曲线在更小 D 处弯平
   (模型容量被噪声饱和),此时 R<0.05 触发而干净语料上仍有空间。
   该情形在 44 的 W/F 结果回来之前不可测。
3. **R<0.05 的读法收窄**:"数据缩放在**这份语料**上到头",不是"数据缩放到头"。
   后续 SFT/扩 N 判断照走,但任何"加数据没用"的结论必须带"在这份语料上"。
4. **识别分支的脏语料嫌疑**:§3b(识别不在 → 换配方)触发时,脏语料是已知嫌疑——
   "换配方"的第一候选就是质量切,不要读成"架构/配方根本错了"。
   §3a(识别在)不受影响:知识在、产出缺,SFT 先行的逻辑与语料质量无关。
5. **β 对恒定噪声比例免疫**:噪声占比不随 D 变(同 mix、同语料快照),
   有效信号 D'=c·D,曲线 L=E+B/(cD)^β=E+(B/c^β)/D^β——β 不变,只有 B 吸收常数。
   β 的已知偏差仍是 warmup 那个(高估),语料质量不新增。
6. **W/F 是本条款的证伪器(链条预注册)**:W 臂(有质量切)vs 六个点(无),
   在 matched D 上比 E 和 R:
   - E_W < E_dirty − 0.05 → 质量切买得到地板,脏 E 被熵抬高证实;
     E 的一切外部比较作废,本树在 W 曲线上重走一遍。
   - R_W > 0.10 而 R_dirty < 0.05 → 非加性弯平证实,"扩 D"分支在干净语料上重开。
   - |E_W − E_dirty| ≤ 0.05 且 R 一致 → 质量切在这个规模价值 ~0,
     脏曲线读数就是模型的数;44 的实验同时回答了它自己的问题。
   - 阈值 0.05 = 噪声锚,与全树一致。
7. **简繁混合(v1.5 指针)**:web_hq 含繁体文档,占比待测(44 计数器)。
   取数路径已证简繁比例跨点常数(train.py:1161 打散),β/形态/R 免疫;
   E 的简繁标签门槛与 fertility 校正规则在拟合协议 v1.8 §10,本树不重复。

## 5. 拟合失败分支(verdict FAIL 或否证形态命中)

- **U 形(++--++)**:两个 regime——最小的点可能在 Kaplan 式的 min-regime 里。
  动作:逐点剔除直到形态消失,两个拟合都报(六点失败拟合 + 缩减拟合),
  下一步是查 regime 边界,不是扩 D。
- **单调漂移**:函数形式错了。动作:换形式(E + B/D^β + C/D^γ 或断幂律),
  这是预注册的备选,不是现场发明。
- **RMS > 2.28σ̂(v1.7 实测填参 = 0.1176;原 0.10 = 2.3×Kaplan σ,σ̂ 实测后与拟合协议 FAIL 线对齐)**:
  曲线不可用。决策只看 §3 的识别水位 + 分域 NLL,不引用 E/β。
- **β 不稳定(LOO Δ > 0.15)**:β 点值不可信,只报 profile 区间;
  不改变上面的分支(分支用的是 Δ_double 和 R,对 β 精度不敏感——β 动 0.15,
  Δ_double 动的量远小于 0.05 的阈值带)。

## 6. 阈值表(全部预注册,锚点写明)

| 量 | 阈值 | 锚点 | 性质 |
|---|---|---|---|
| Δ_double 可测 | ≥ 0.05 nat | run-to-run 噪声(Kaplan) | 外部测得锚,1× 选定 |
| R 有空间 | > 0.10 nat | 2× 噪声 | 选定 |
| R 到头 | < 0.05 nat | 1× 噪声 | 选定 |
| 识别在 | 孪生 >0.75, 最小对 >0.75, LAMBADA >0.30 | 旧架构实测 0.949/0.356 − 余量 | 选定,锚旧架构;迁移规则见 §3d |
| 识别不在 | 孪生 <0.60 或 最小对 <0.60 | 50% 地板 + 10pt(=面板无分辨率带宽) | 选定 |
| 生成式在地板 | pass@1 < 0.02 | 实测 2.8%(k8)/ 0%(0.8b) | 选定,锚测得 |
| 改配比触发 | 域斜率极差 >2×SE | 95% 显著性惯例 | 选定惯例 |
| 改配比权重闸 | 最平域 ≥10% | 小域挪不动聚合 | 选定,无测得锚 |
| 改配比成功 | 同 D 改善 > 0.05 | 1× 噪声 | 复用 0.05 锚 |
| 改配比幅度 | ≤10pt 权重 | 线性外推未验证 | 选定 |

**0.05 的复用声明**:本树四个 0.05(Δ_double、R 到头、D* 噪声带、改配比成功线)
与拟合协议的 ACCEPT 边界同源,全部是"1× Kaplan run-to-run 噪声"的有意复用。

## 7. 这份树不决定什么

- 不决定 SFT 的配方(那是 SFT 阶段自己的预注册)。
- 不决定扩 N 扩到多少(新阶梯的设计,另一份预注册)。
- 不决定改配比的具体新权重(44 的实验设计给成本与候选配比;这棵树只裁决**做不做**)。
- 不决定"模型能不能用"的产品判断——它只决定**下一步实验往哪走**,证据标准是什么。

## 8. 表达能力阶梯读法(v1.8,用户新方向,3.24b 落盘前写死)

背景:表达能力(产出,不只是判别)成为命名目标,预训练数据拟扩 ~10×(3.6285B → ~36B)。
0.2b 实测:L2(lambada-zh two-way)90.4% vs O1(open acc@1)16.0%——**74pt gap 是
表达能力最干净的操作化,且免费(面板已有两半)**。O1 不在 SKIP 类:旧 arch 3.24b
held-out 实测 35.6%(200M 有演示量程)、acc@5/acc@1 = 2.3×(内部 headroom 结构)、
seed 噪声 s_O1 = 1.02pt(df=3)远小于 gap。机制前提已测:cosmopedia 模板浓度
6.38× 于 web_hq(top-100 句框覆盖 48.2% vs 7.6%,44 实测,
mlm.corpus.cosmopedia_template_concentration)——必要性成立,后果(训练结果)归本节。

**量**(每 checkpoint):L2、O1、O5(acc@5)、CE(C-Eval)、GAP = L2 − O1。

**噪声地板(自校准,同 A/B 纪律)**:s_M = 四个 0.2b seed 的 seed SD(df=3,
be.panel_expressive_seed_variance):L2 0.54pt、O1 1.02pt、O5 1.47pt、CE 1.27pt、
GAP 0.90pt。端点移动可读当且仅当 |ΔM| ≥ 4.65·s_M(t 版,df=3,4-seed 均值对 1-seed:
(t₀.₉₇₅,₃+t₀.₈,₃)·√(1/4+1) = 4.16·1.118)→ 阈:L2 2.5、O1 4.8、O5 6.8、CE 5.9、GAP 4.2pt。

**形态(看到数之前写死)**:
- **A 容量型**:O1 移动 ≥ 阈 且 GAP 收窄 ≥ 阈 → 表达是数据量问题;10× 同配比
  应该能动表达;配比假说被削弱。
- **B 配比型**:L2 和 CE 各移动 ≥ 阈 且 O1 移动 < 阈 → 知识动、表达不动;
  配比假说存活;10× 同配比预测不动表达,10× 构建需要改配比。
- **C 齐动型**:O1 移动 ≥ 阈 但 GAP 在噪声内 → 两者都 scale,容量有效;假说削弱。
- **D 不可读**:L2 也移动 < 阈 → 阶梯跨度太小,该仪器在 200M 不能转向;升级
  (更大阶梯或别的仪器),不硬读。

**非对称(预注册)**:阶梯能**证伪**配比假说(O1 动了 = 同配比容量动表达),
不能**证实**它——O1 在 3.24b 平不证明在 36B 平(表达可能需要更多容量解锁)。
证实性检验是 10× 构建的同配比对照臂(下条)。

**10× 构建的证伪设计(预注册)**:配比假说的判决性检验是同 mix 下
O1(36B) vs O1(3.24B)。**10× 构建必须含同配比臂(或同 run 内的同配比
checkpoint)**;若 10× 构建改了配比且无同配比对照,假说对它不可证伪——
现在就声明,不事后补。

**不做的实验(预注册)**:0.2b 配比 A/B 不跑。原因不是无分辨率(O1 的 seed SD
1.02pt,4v4 MDE = 2.4pt,可读)——是**答错问题**:它测 0.2b 的配比效应,
假说是关于 36B 的,尺度不匹配。判决性检验在 3.24b+(阶梯 + 10× 对照臂)。
