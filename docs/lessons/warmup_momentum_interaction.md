# 两个常数在同一个窗口里相互作用，而只有一个被看过

500M 定型为 d=1024 / L=32（2.7 倍深度，宽度不动），fb 问 `Cfg.warmup = 20`
在 32 层上还对不对。

**答案是"保留 20"，但真正的发现不在 warmup 这一侧。**

## 1. 机制：warmup 在 Muon 下防的不是它在 Adam 下防的东西

warmup 的通常理由是压住早期过大的步长。**在 Muon 上不存在这件事。**
Muon 对更新做正交化，t71 的 check 4 与 check 6 分别测到：更新范数在梯度
**尺度**跨 1e6 时是平的（16.153–16.209），在梯度**噪声**（即 batch，
1→196）跨越时也是平的（16.15–16.22，只有方向改善，cos 0.08→0.67）。

所以对 169 个矩阵参数（L=12 时是 64 个）而言，warmup 只是在 ramp `lr`
本身，而每层的相对步长 `lr/||W||` 本来就与深度无关——固定宽度下
`||W||` 均值在 L=12 与 L=32 都是 30.78。

**深度在 Muon 这一侧不引入新的早期风险。** 这是 warmup 保留 20 的直接理由。

## 2. 真正的发现：LR 在 momentum 走完 13% 时就满了

`train.py:1121` 用一个**写死的 150 步**日程 ramp Muon 的 momentum：

```python
g["momentum"] = 0.85 + 0.10 * min(1.0, step / 150)
```

`train.py:1895-1896` 的 warmup 在第 20 步结束。两者对齐起来：

| step | lr_mult (warmup=20) | momentum | 平均窗口 1/(1−m) |
|---|---|---|---|
| 0 | 0.050 | 0.8500 | 6.7 步 |
| 20 | **1.000** | **0.8633** | **7.3 步** |
| 50 | 1.000 | 0.8833 | 8.6 步 |
| 150 | 1.000 | 0.9500 | 20.0 步 |

**LR 在第 20 步达到满值，此时 momentum 才走完自己 ramp 的 13%**，动量缓冲的
有效平均窗口是 7.3 步，而终值对应 20 步。

两个常数都定在 L=12，都没有再被看过，而它们相互作用的窗口，正是"LR 过高"
会现形的那个窗口。

**150 是机制指向的那个旋钮，warmup 是所有人会去伸手的那个旋钮。**

这条不主张改动——没有测量支撑任何新值。它主张的是：下次有人担心早期窗口，
先看 150，再看 20。

## 3. 一个数被搬离它的测量有多远

warmup=20 的证据是 de 在 0.2b 点的一次测量：warmup=2 得到 final val 3.658，
warmup=20 得到 3.135。

**这确立了一个下界在 2 以上，除此以外什么都没确立。20 以上从未被测过。**

`Cfg.warmup` 的注释把它读成"拟合出来的"，而它是**一个被测区间的下端**在被
当作最优值使用。数字保留，描述要改——这是同一天 `loader.py` docstring 的同
一个缺陷类：**散文断言的比测量支撑的更多，而下一个读者拿走的是散文。**

绝对步数在不同 run 里的占比：

| run | 步数 | warmup 20 占比 |
|---|---|---|
| 0.2b 点（20 在这里被测） | 191 | **10.486%** |
| 3.24b 点 | 3,090 | 0.647% |
| 500M 到 30B（本次） | 32,697 | **0.061%** |

**这个常数被搬到了距离它的测量 171 倍远的地方**（10.486 / 0.061）。不是错，
是未测——而这两者的下一步动作不同。

## 4. 可复用的形状

三条，按可迁移性排序：

**一、一个常数的"适用范围"要连同它的证据方向一起记。** "warmup=2 差于
warmup=20"是**单侧**证据。单侧证据支持"不要低于 20"，不支持"20 是对的"。
写下常数时把测过的区间写进去，而不只写选中的值——否则下一个人读到的是一个
看起来两侧都被验证过的数。

**二、当一个参数被改动时，先问"它和谁共享一个时间窗口"。** warmup 与
momentum ramp 从未被一起看过，因为它们在代码里隔了 780 行，且分属"调度"与
"优化器"两个概念。**相互作用不出现在任何一方的定义里。**

**三、机制指向的旋钮和直觉指向的旋钮经常不是同一个。** 这次直觉说 warmup
（深度变了，早期更危险，加长 warmup），机制说 momentum ramp（Muon 下 warmup
防的东西不存在，而 150 步的 ramp 确实横跨整个早期窗口）。**先算机制，再伸手。**

## 5. 作废条件

- **150 步 ramp 或 warmup 被实测**：本文第 2 节从"两个未检查的常数"降级为
  一次有读数的选择。
- **优化器不再是 Muon**：第 1 节整节失效，warmup 恢复它在 Adam 下的常规作用，
  深度可能重新成为 warmup 的变量。
- **宽度变动**：`||W||` 的深度无关性是在固定宽度下测的，第 1 节的推理要重跑。
