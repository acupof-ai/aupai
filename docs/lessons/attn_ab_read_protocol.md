# attn_every A/B 读法(预注册)

e1 的设计,fb 的三条读法,本文件坐实判据并补上 fb 要求自算的三项。
**设计是 e1 的,判据不是它自己的**——读数规则在看到数之前冻结。

## 0. 设计(照录,责任在 e1)

- 臂 A:`--attn_every 1`(12 层 GatedMLA 全注意力),194M 参数
- 臂 B:`--attn_every 4`(9 KDA + 3 GatedMLA),206M 参数(+5.8%)
- 4 seed × 2 臂 = 8 run,0.2b 点(218 步量级),主指标分域 NLL,e1 声称 MDE≈0.035

## 0.5 排期与门(2026-08-30 fb 排期,门的位置本文件预注册)

1. **先跑 4 个 `attn_every 4` seed(24 min,无条件必跑)**:seed 0 是阶梯的 0.2b 点;
   4 个的散布是 σ̂(df=3);44 的 F 臂也是它们。
2. 算 s₄ 和真实 MDE = 2.371·s₄(本文件 §1)。
3. **门(看到 σ̂ 之前写死)**:
   - **MDE ≤ 0.08 → 跑 4 个 `attn_every 1`**。理由:200M 架构差在 0.2b 的现实区间
     是 0.01–0.05 nat,0.08 是该区间的天花板;MDE 压过天花板,实验只能产出可预测的
     "无分辨率",那四个字现在就能写,跑完是浪费 24 分钟。
   - **MDE > 0.08 → 不跑,A/B 延到 3.24b**,用阶梯自己的 checkpoint 免费重问
     (本就是空结果那一支的归宿)。
   - **CI 带为什么不进门**:门的 σ̂ 只有 df=3,CI 因子 6.5×——MDE_point=0.08 时
     真实 MDE ≤0.08 的概率约 50%,CI 无法把门移动任何有意义的量;拿 6.5× 的带放门
     是用噪声当信息。CI 的岗位在**读数**(§1):gap 落进 [1.52s, 5.22s] 带 = 无分辨率。
4. 门开 → 跑 4 个 `attn_every 1`;门不开 → 直接开阶梯。

**时序裁决(fb 2026-08-30)**:A/B 全部跑完才开阶梯,中途换臂不存在。
若将来真出现"阶梯跑了一半才知要换架构":**绝不中途换**——同一条曲线不许混两个架构,
跑完当前架构,另一个架构重跑整条。混架构的曲线不是差曲线,是没有意义的曲线。

**门已触发(2026-08-30,σ̂ = 0.0516 实测后)**:四个 attn_every 4 seed 跑完
(ds.seed_variance_0p2b:s0 3.691 / s1 3.762 / s2 3.679 / s3 3.638,σ̂ = 0.0516,df=3)。
按本文件 §1 冻结公式 MDE = 2.371·s₄ = **0.1223**(fb 用正态近似 2.8·s·√(1/2) = 0.1021,
两公式都 > 0.08,裁决对公式选择稳健)。**裁决:attn_every 1 臂不在 0.2b 跑**——
8+8 也只到 0.0722 仍过门,不是加 seed 能解决的。KDA A/B 的 3.24b 重问按 §6 配对设计走
(fb 更正:不是零成本——阶梯只产 attn_every 4,重问要训配对臂;更大 D 对独立 MDE 无帮助)。fb 在看到数之前 commit 了分支(20e1b7a)。
e1 原声称的 MDE≈0.035 要求 s=0.015,实测 σ̂ = 0.0516 是其 1.47×——0.035 是拟合残差
被借用为 seed 方差(两类量的混淆),按 3.9pt 先例记为不可复现,不采用。
Kaplan sanity:σ̂ = 0.0516 < 0.10,整批解读不降级为趋势。

## 1. MDE 自校准(替代 e1 的 0.035——它是估的)

4v4 两样本比较,MDE = (t₀.₉₇₅,₆ + t₀.₈,₆)·s·√(2/4) = **2.371·s**,s = seed 间 SD。

- e1 的 0.035 要求 s = 0.015。**项目内部 seed 方差从未测过**(拟合协议 v1.4 自己声明
  "无内部重复 run");唯一锚点是 Kaplan run-to-run 0.05 → MDE 应为 **0.118 ≈ 0.12**。
  0.035 是把未测的方差当成了已测,按 3.9pt 先例记为**不可复现**,不采用。
- **冻结公式**:决策阈值 = 2.371·s_pooled,s_pooled 从 8 个 run 自身的 seed 散布算
  (合并臂内 SD)。MDE 不是假设,是从这批 run 里长出来的。
- **df=6 的不确定带必须报**:s 的 95% CI ≈ [0.64s, 2.20s](χ²,₆),MDE 同比例。
  gap 落进 [2.371·0.64s, 2.371·2.20s] 带内 = **无分辨率**,不读。
- Kaplan 0.05 是外部锚(3M 参数、他们的数据),只作 sanity check:s_pooled 若 >0.10,
  说明 0.2b 点 seed 噪声比 Kaplan 还大,整批 8 run 的解读降级为"趋势"。

## 2. 主指标:聚合 val NLL,事前定死

- **主指标 = 聚合 val NLL**(固定 val 集,与拟合曲线同量、同集)。一个数,无多重比较。
- **分域 NLL 全部降为二级诊断**:七个域(web_hq/textbook/wiki/en/math/code/chat)全报,
  禁止挑最好看的域报。任何"某域赢了"的决策性主张须过 Bonferroni(0.05/7),
  否则只是诊断,不是证据。
- 理由:七域挑一 = 七次比较报一次,family-wise α 涨到 30%。

## 3. 次指标:0.2b 上只报趋势,不进决策

CLiMP(4.4pt/范式)、LAMBADA-zh(4.1pt)、math v2 似然孪生(2.5pt)的 MDE 是
**采样分辨率**,在任何 checkpoint 上都成立;但:

- known-answer 校准在 3.24b **旧架构**上做的,0.2b 新架构的读数贴地板,
  臂间 gap 未知且大概率小;
- **冻结规则**:次指标同时满足 (a) 臂间 spread > 该指标 MDE 且 (b) 读数在地板+MDE 之上,
  才可写进决策;否则只报趋势,**事后不得当证据引用**(空结果不认证格子,
  也不允许事后把趋势读数升级成证据)。

## 4. 决策树(fb 三条,坐实)

```
gap = 聚合 val NLL(B) − 聚合 val NLL(A),阈值 = 2.371·s_pooled(§1)
├── A 赢 ≥ 阈值(全注意力更好)→ 阶梯改跑 attn_every 1
│   时序已裁决(fb):A/B 先于阶梯跑完,不存在中途换臂;
│   若未来出现阶梯中途换架构,绝不换——跑完当前架构,另一个重跑整条(§0.5)
├── B 赢 ≥ 阈值(KDA 更好)→ 不可直接读,先跑配平臂
│   混淆是二元的:206M vs 194M(+5.8%)的容量差对任何 margin 都存在,
│   margin 大小不改变混淆是否存在(fb 的推导,复核成立;补一句:没有 200M 的
│   容量弹性实测,margin 也无法用来校准混淆——配平臂是唯一解法)。
│   配平臂:--ffn_hidden 3392(全注意力臂加宽到 206M 量级),4 seed。
│   验收:两臂参数数从 run 日志实测,差 ≤1%(信日志不信配置名)。
│   ├── 配平后 B 仍赢 ≥ 阈值 → KDA 留下,容量混淆排除
│   ├── 配平后平或输 → 之前的赢是容量,KDA 不留
│   └── 配平臂自身 seed 方差同样按 §1 读
└── |gap| < 阈值 → KDA 留下,记"0.2b 无分辨率"
    到 3.24b 用阶梯自己的 checkpoint 重问(阶梯两臂都在跑,零额外成本)。
    e1 原设计"无显著差异 → 删 KDA"违反空结果纪律,作废。
```

## 5. 这份读法不决定什么

- 不决定阶梯的时序(换臂点)——fb 裁决。
- 不决定配平臂之外的架构消融——另一份预注册。
- 次指标无论结果如何都不进本决策(§3)。

## 6. 配对设计修正案(2026-08-30,探针落数前写死)

背景:独立 4v4 的门已触发(§0.5),fb 更正"3.24b 免费重问"——阶梯只产 attn_every 4,
重问要训第二个 3.24b 模型;且更大 D 对独立样本 MDE 毫无帮助(3.24b 4+4 独立 = 0.1022,
~824 GPU-min,仍过门)。e1 提出配对:两臂同 seed → 共享数据顺序和初始化,
比较变成配对差,管辖量是 σ_d(差的 SD)而非 σ(run 的 SD)。

**不变的部分(只换数字,不换规则)**:
- 主指标 = 聚合 val NLL(同量同集);门限天花板 0.08(它是效应大小的现实区间,与设计无关);
  次指标 Bonferroni/趋势-only;决策树三分支(A 赢→换、B 赢→配平臂、|gap|<阈→KDA 留);
  配平臂(容量混淆是二元的,配对不触及);CI 在读不在门;noise-loose 非对称。
- §4 的"空结果不认证格子"纪律不变:配对也一样,无分辨率就是无分辨率。

**变的部分(数字)**:
- **MDE 公式换配对版**:(t₀.₉₇₅,n-1 + t₀.₈,n-1)·s_d/√n,df = n−1。
  独立版 2.371·s 对配对设计作废。门限 0.08 对 s_d 的要求:

  | 配对数 n | df | MDE 因子 | 过门要求 s_d ≤ |
  |---|---|---|---|
  | 2 | 1 | 9.96 | 0.008 |
  | 3 | 2 | 3.10 | 0.026 |
  | 4 | 3 | 2.08 | 0.0385 |
  | 6 | 5 | 1.43 | 0.056 |

**新规则 1——最少 2 对**:n=1(df=0)无法估 s_d,没有数据驱动的 MDE,
配对 1+1 在统计上不存在。df=1 的 t₀.₉₇₅ = 12.7,2+2 配对要 σ_d ≤ 0.008 才过门——
探针会显示这现不现实。

**新规则 2——门的输入是探针的 s_d,不是 σ̂ = 0.0516**:0.0516 预测的是独立设计;
σ_d = σ√(2(1−ρ)) 是新量,ρ = 两臂 seed 效应的相关,正是探针要测的。
门在探针落地前无法预算。流程:探针(0.2b,便宜)→ s_d → 可行 n 的配对 MDE →
门(≤0.08 跑 / >0.08 搁置)→ 3.24b。

**证伪器(预注册)**:配对只有在共享 seed 真的诱导相关时才赚钱。
若探针给出 σ_d ≈ σ√2(ρ≈0),配对什么都没买到——退回独立经济学,
而独立经济学已经过门失败 → **A/B 在 200M 判死,不再换设计复活**。
探针因此同时是配对设计的证伪器。

**探针的两个读数(e1 的设计,记录在案)**:
1. 同 seed 同臂跑两次 → σ_nondet(纯非确定性)。预注册不等式:σ_d ≥ √2·σ_nondet
   (差的方差含两臂各自的非确定性)。若 √2·σ_nondet 单独就超门限要求,配对直接死,
   不用等跨臂探针。
2. 同 seed 两臂、2 个 seed → 首个 s_d(df=1,噪声大,但够判 3.24b 配对是否在局内)。

**df=1 读数规则(预注册)**:2 对的 s_d 点估计 CI 因子 ~31×(χ²₁),直接过门等于掷硬币。
规则:点估计决定去向;若 n=4 的探针 MDE 落在门限 0.08 的 ±20% 带内([0.064, 0.096]),
先加第 3 对(0.2b,~12 GPU-min,df=2)再定 3.24b 跑不跑——df=1 噪声区里的便宜保险,
同"承诺贵 GPU 前先买便宜 df"的一贯处理。带外(明显过/明显不过)不追加。

**成本现实**:3.24b 单跑 ~103 GPU-min;配对 4+4 ≈ 824 min(若阶梯的 3.24b run
seed 复用为一对成员,7 跑 ≈ 721 min);3+3 ≈ 618 min。阶梯跑完前不启动。

**非确定性性质(probe 1 实测,ds.nondeterminism_washes_out)**:同 seed 同臂重跑,
逐 step loss 从第 10 步起发散(散布 0.02–0.05)但端点收敛(差 0.001)——
非确定性进入但不累积。**run 间比较只读端点 val,逐 step 曲线 diff 不是真实差异的证据**;
σ̂ = 0.0516 因此基本是纯 seed 方差,门的数字是干净的。

**fb 直觉的一处修正**:"符号形态准则不变地搬过来"——符号形态(§4)是**拟合**的
判据,从不进 A/B;A/B 的对应物是 CI 带读法,它随配对 df 搬过来。其余直觉成立。
