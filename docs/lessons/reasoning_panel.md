# 推理仪器栈(预注册,3.24b 落盘前)

目标变更:通用中文 LM → 推理模型(代码+数学,~30B token)。面板为"200M 上什么有分辨率"
而建,那个问题它答得好;但只有 math_v2_like 触及新目标,且它是**判别**任务
(在候选里选对答案),不是**推理**任务(产出推导)。GAP 仪器今天暴露的正是这个差:
同一份题,two-way 94.78、open-ended 30.90。**math_v2_like 94.69 是数学的 two-way;
数学的 open-ended 我们一个数都没有。**

## 1. 仪器栈(判别 → 产出桥 → 产出)

| 层 | 仪器 | 测什么 | 成本 | 现状 |
|---|---|---|---|---|
| L0 | math_v2_like | 判别(金答案 vs 扰动答案的似然) | 零 | 已有,在动(+11pt) |
| L0' | 代码判别(按执行通过率排序的似然) | 判别 | 数据集+脚本 | **缺口,需建** |
| L1 | few-shot 续写数学 | 产出(格式桥) | 零 GPU,换 prompt | **Q1 的判决实验** |
| L2 | 轻 SFT → pass@k | 产出(真仪器) | 一次 SFT run | L1 读数后定 |

**L1 是关键**:base 模型不主动解题——math-500 在 base 上 0/500 一半是格式问题
(base 续写文本,不回答问题),不全是能力缺失。few-shot 续写(给 2-3 个已解例题
再让模型续)桥接格式差,零 GPU。读法:最终答案精确匹配(boxed 或末位数字)。

**L2 是标准路径**:每个推理模型都走 SFT/RL。轻 SFT 教格式,pass@k 测能力。
SFT 后的 3.24b 若 pass@k 非零,项目可测;若仍零,200M 装不下推理产出,
需要 N 或别的路径——**这是项目可测性的判决,不是能力判决**。

## 2. Q1 的判决(3.24b 落盘后立即跑,预注册)

**在 3.24b checkpoint 上跑 L1(few-shot 续写数学,N≥500 题)**:
- **非零(>2δ,δ=1.4/√N≈6.3pt@500)**:仪器存在,产出半有信号。
  进入 L2 设计(SFT → pass@k 作为 30B 构建的转向量)。
- **零或 <2δ**:格式桥接不动,base 在 3.24b 仍不产出。
  进 L2(SFT 是唯一路径);L2 仍零 → **200M 规模上推理产出无仪器,
  这是本轮最重要的结论**——它改变项目可测性,先于可实现性。

**不跑的**:zero-shot 生成数学在 base 上(SKIP,格式+能力混淆,0/500 已证)。
SKIP 的是 zero-shot base,不是产出本身。

## 3. 可验证性不对称(fb 的 Q3,确认并写死)

数学/代码答案可执行验证——对就是对,错就是错,不需要裁判,不需要相似度。
这带来两个后果:

1. **标签无 MDE**:N 题精确匹配的误差是二项的 δ=1.4/√N(p=0.5 最坏情形),
   500 题 → 6.3pt,1000 题 → 4.4pt。没有 seed 方差进标签(执行是确定性的)。
   seed 方差仍在模型侧(不同 seed 不同模型),但单次测量的误差是二项的,
   比 NLL 的 σ̂=0.0516 锋利得多。
2. **A/B 更便宜**:推理数据配比的 A/B 用 pass@k,误差是二项+seed 方差,
   大概率比 NLL A/B 锋利。可验证标签移除了裁判/相似度问题(那是质量头沉没的原因)。

## 4. §8 形态迁不迁移(fb 的直接问题)

**形态逻辑迁移,具体指标不迁移。** §8 的四形态(A 容量/B 配比/C 齐动/D 不可读)
本质是"判别半饱和时产出半动不动"——这个逻辑与目标无关,推理版照用:
- pass@k 随 D 动、判别饱和 → 容量型;
- 判别动、pass@k 不动 → 配比型(或容量天花板);
- 都不动 → 不可读。

但 §8 的指标(lambada L2/O1/GAP)是表达能力的,不是推理的。**§8 不替换,
加兄弟**:推理版需要自己的产出半(L1/L2 的 pass@k)和判别半(math_v2_like +
代码判别),形态逻辑照抄。**当前阻塞:推理的产出半不存在(base 上 pass@k=0),
形态无法触发——L1 是前置条件。**

## 5. 代码侧的缺口

代码判别仪器(L0')不存在:需要一个带测试的代码题数据集(HumanEval/MBPP 类),
测模型是否给执行通过的完成更高似然。这是 3b/44 的数据活,不是我的读法活——
但**30B 构建要转向代码推理,这个仪器和 L1 数学一样是前置条件**,并列优先级。

## 6. 代码判别仪器规格(2026-08-30,fb 要)

**形状**:逐题胜率——每题有 prompt + ≥1 执行通过的解 + ≥1 执行失败的解,
测模型给通过解的 per-token NLL 是否低于失败解。胜率 = 通过解 NLL 更低的题占比。
这是 math_v2_like 的代码版:标签来自执行,不是裁判。

**已知答案案例(两层)**:
- **仪器验证层(易扰动)**:取正确解,单算子变异(`+`→`−`、`<`→`>`、`=`→`!=`),
  变异解必挂测试。模型应在 >90% 的题上偏好未变异解(同一代码差一个 token)。
  不偏好 = 仪器坏了,不是模型差。自动化变异,零人工。
- **转向量层(难扰动)**:变异算法(错边界、反条件、漏 edge case)——模型生成的
  失败解(采样 K 个、执行、取挂的)是最便宜的来源,但可能错得太明显。
  难扰动给 headroom,易扰动只验证仪器。
  **冻结纪律(fb 2026-08-30)**:模型生成的失败解随模型改进而变难,
  3.24b 的分数与 30B 不可比(对手在动)。干扰子集从**一个 checkpoint 冻结**,
  跨 checkpoint 复用,不重新生成。

**分辨率**:二项 δ=1.4/√N。N=500(MBPP 量级)→ 6.3pt;N=1000 → 4.4pt。
math_v2_like 在阶梯上动了 11pt,6.3pt 够转向用。

**失败模式(预注册)**:
1. **扰动太易**:失败解有语法错误或显然错 → 胜率饱和 ~100%,无分辨率。
   已知答案层就是查这个的。
2. **长度/分词混淆**:通过/失败解长度不同,总 logprob 有偏。用 per-token NLL,
   或长度配对(math_v2_like 的等长扰动纪律)。**但 per-token 不够(fb)**:
   代码在中文 BPE 下分词碎,失败解与通过解的碎裂程度可能系统性不同——
   比较前先查一对候选的 token 数是否相近;系统性不同则 per-token 归一化失效,
   需长度配对或按碎裂度分层。
3. **训练污染**:题在训练语料里 → 测的是记忆不是能力。用留出题
   (holdout_v2 纪律,sha1 切分 + 验收扫描)。**3b  owns 仪器(fb)**:
   MinHash 已知答案已验证(296/296 召回,0/72 误报),留出切片在指纹之前切,
   与 LAMBADA-zh 留出同序(两次独立扫描验证过)。
4. **天花板**:胜率 >95% 后动不了。math_v2_like 阶梯动 18pt(76.69→94.69)后耗尽——
   近天花板的指标分不出"好改动"和"极好改动",而这正是转向量的全部工作。
   **headroom 是设计参数,不是事后发现的(fb 立规)**:代码仪器从难扰动起步。

**swap 稳定性**:通过/失败解顺序互换,胜率应不变(math_v2_like 已验 0.9625/0.9625)。

## 7. 可验证答案的经济学(fb 要求记为事实)

**在答案可执行验证的任务上,配比 A/B 可能买得起——同样的 A/B 在 val NLL 上买不起。**
标签误差是二项的(δ=1.4/√N,500 题 6.3pt),seed 方差不进标签;
val NLL 的 σ̂=0.0516 杀死了 KDA A/B、让 AttnRes campaign 买不起。
A/B 仍有模型 seed 方差,但标签是锋利的。**这是本回合约束的反转:
转向推理后,可测性上升,不是下降。**

## 8. 独立性判据(2026-08-30,用户指令"维度必须独立且有区分度",fb 实测相关矩阵后)

fb 的矩阵:L2/O1/O5/math_v2_like/dloss 两两 r=0.90–1.00(n=6),CE 是噪声,
mp(0.48–0.72)是唯一带 val loss 没有的信号的条目。**裁决:fb 的弱读法成立——
它们在 D 轴上冗余,不在一般意义上冗余。**

**为什么弱读法对且够行动**:六点只在 D 上不同。沿单一缩放轴,任何随规模改善
的量都与其他随规模改善的量相关——矩阵无法区分"冗余指标"和"恰好一起缩放的
不同能力"。但 **D 轴决策只需要 D 轴冗余**:一个指标沿 D 是 val loss 的近似确定
函数,它对 D 决策就不携带信息,无论它测的是不是同一种能力。弱读法精确等于
行动所需。

**矩阵不许可什么**:不许把它们作为能力度量退役,不许声称它们测同一件事。
反例就在面板里:L2 与 O1 沿 D 相关 0.94,但它们的**差**(GAP)是表达能力的
转向量——两个相关指标可以在对比中携带独立信息,相关矩阵看不见对比。

**n=6 的 CI 很宽**(r=0.90 的 95% CI 约 [0.36, 0.99]):"一个维度"是提示不是
结论。行动(降级 D 转向声音)对 CI 稳健,因为只需"沿 D 近冗余";GAP 无论
如何保留。

**面板重组(按能力轴,不按格式)**:
- 语言建模:dloss(D 轴主指标)
- 表达:GAP(L2/O1 降为输入,不再独立发声)
- 数学判别:math_v2_like(沿 D 近冗余,保留为数学轴代表,不作 D 转向)
- 句法:minimal_pairs(唯一验证过的独立信号)
- 知识:C-Eval 死(地板,无区分度)
- O5:与 dloss r=1.00,纯冗余,降级为诊断

**新指标准入判据(e1 的推理指标、44 的代码 eval,完工前需要)**:
席位靠**在非 D 轴上分离**赢得,不靠沿 D 相关:
1. **配比轴**:10× 同配比对照臂 vs 构建臂——mix 变而 D 不变下分离 = 独立。
2. **训练阶段轴**:base vs SFT——SFT 动而 val loss 不动 = 独立。
3. **架构轴**:attn_every A/B(3.24b 重问)——架构分离而 val loss 不分离 = 独立。

操作化:先对 D(或 val loss)回归取残差;残差是噪声 → D 冗余,再查非 D 轴
分离。**D 冗余且从未在非 D 轴上测过 = 从 D 面板降级的候选,不是删除候选。**
代码判别和 L1/pass@k 沿 D 会和一切相关——预期的,不是缺陷;席位由能力轴
覆盖保证,独立性检验决定转向声音,不决定存在。
