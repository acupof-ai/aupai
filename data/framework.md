# 世界底层规律与逻辑链

**用法**：每个条目 = 一句日常话 + 一条因果链 + 关联代号 + 关联条目。代号是跨领域共通的骨架，条目是骨架在各领域的具体长相。先看代号表，再按需查条目。

## 0. 共通代号（10 个骨架）

| 代号 | 名字 | 一句话 |
|---|---|---|
| **F** | 反馈 | 结果会回头改变原因。正反馈放大，负反馈拉回。 |
| **E** | 耗散 | 不持续投入维护的东西，默认走向混乱和衰败。 |
| **S** | 筛选 | 有多样性 + 有淘汰 = 自动变得适应环境。 |
| **C** | 复利 | 小的变化率，乘以足够长的时间，会变成巨大差距。 |
| **L** | 约束 | 稀缺的那一样东西决定了整体的形状和上限。 |
| **M** | 边际 | 多做一单位的收益或代价，随着数量变化而变化，不是恒定的。 |
| **P** | 路径依赖 | 早期的选择会锁死后来的选项，改起来比当初选便宜得多。 |
| **G** | 涌现 | 许多简单个体按简单规则互动，整体会出现个体没有的性质。 |
| **T** | 权衡 | 几乎没有免费午餐，得到一样往往要放弃另一样。 |
| **I** | 信息差 | 谁知道什么、知道多少，决定了谁占便宜、谁吃亏。 |

## A. 物质与能量

**A1 能量守恒** `L T`
能量不会凭空出现，只会换形式。
链：要做事 → 必须有能量来源 → 能量来源有限 → 做事的总量有上限。
关联：A2、D1、B1

**A2 熵增（东西默认变乱）** `E`
不管的房间会越来越乱，管了才整齐。
链：秩序需要能量维持 → 停止投入 → 秩序自然瓦解 → 维护成本是永久成本，不是一次性成本。
关联：B2、E3、F4

**A3 最小阻力路径** `L S`
水往低处流，电走电阻小的路，人也一样。
链：多条路可走 → 代价最低的路被走得最多 → 那条路被进一步踩平 → 其他路荒废。
关联：C3、D4、P

**A4 尺度效应** `M G`
东西变大，性质会跟着变，不是简单放大。
链：体积按三次方长，表面按二次方长 → 比例变了 → 大象散热难、蚂蚁摔不死 → 同样的设计换个尺度就失效。
关联：E2、F3

**A5 相变与临界点** `F G`
水到 100 度才开，99 度不开。变化常常不是渐进的，是跨过一个点突然翻转。
链：压力持续累积 → 表面没变化 → 越过阈值 → 整体状态瞬间切换 → 很难退回去。
关联：E5、D6、G4

**A6 惯性** `P`
动的东西倾向继续动，停的东西倾向继续停。
链：改变状态需要额外的力 → 没有额外的力就维持现状 → 现状本身就是一种力量。
关联：C5、E4

## B. 生命与演化

**B1 演化 = 变异 + 筛选 + 时间** `S C`
不需要设计师，只要有差异、有淘汰、有足够的代数，就会自动出现"像是设计过的"东西。
链：个体有差异 → 环境淘汰一部分 → 留下的更适应 → 下一代从留下的开始 → 反复叠加。
关联：D3、E1、F5

**B2 活着就是逆着熵走** `E L`
生物是靠不断吃进能量来维持自身秩序的机器。
链：不吃 → 秩序无法维持 → 死亡 → 所以所有生物的第一目标是获取能量。
关联：A2、C1

**B3 适应有代价** `T`
擅长一件事的结构，通常不擅长另一件事。
链：资源有限 → 投入一处 → 另一处缺失 → 没有"全能"的生物，只有"在当前环境下够用"的生物。
关联：D5、E6

**B4 红皇后效应（跑才能原地不动）** `F S`
你进步，对手也进步，相对位置不变，但不进步就落后。
链：竞争者互为环境 → 一方改进 → 另一方的压力变大 → 被迫改进 → 军备竞赛永不停止。
关联：D2、F6

**B5 局部最优陷阱** `P S`
演化只看下一步好不好，不看终点在哪，所以会卡在小山顶上下不来。
链：每一步只能选略好的方向 → 走到附近最高点 → 再往任何方向都是下坡 → 哪怕远处有更高的山也去不了。
关联：C4、D4、F2

**B6 冗余换稳健** `T E`
两个肾、备份文件、多条供应链——多出来的那份平时浪费，出事时救命。
链：单点会坏 → 备份增加成本 → 换来失败时不致命 → 效率和稳健互为代价。
关联：E7、G3

## C. 人的认知与行为

**C1 激励决定行为** `F I`
看一个人做什么，先看他得到什么。
链：行为带来奖励 → 行为被强化 → 奖励设错了 → 行为跟着歪 → 制度问题通常是激励问题。
关联：D1、E1、E4

**C2 损失比收益更痛** `M`
丢 100 块的难受，比捡 100 块的高兴更强烈。
链：大脑对损失更敏感 → 人倾向保住现有的 → 宁可不赌 → 现状被过度保护。
关联：A6、G2

**C3 省力是本能** `L`
大脑能不想就不想，能走捷径就走捷径。
链：思考费能量 → 能量曾经稀缺 → 默认用直觉 → 直觉在熟悉环境好用、在新环境出错。
关联：A3、C4

**C4 人只看得见自己在找的东西** `I`
注意力是过滤器，先有框架，再有"事实"。
链：信息太多 → 必须过滤 → 过滤器来自过去经验 → 不符合过滤器的信息被忽略 → 越来越确信自己是对的。
关联：B5、E5、F1

**C5 习惯是压缩的决定** `P C`
重复几次后，行为从"选择"变成"自动"，省力但难改。
链：重复 → 大脑建立通路 → 不再需要决定 → 通路越走越深 → 改变要付出比建立时更多的力气。
关联：A6、C3

**C6 身份先于观点** `I G`
人先决定"我是谁"，再决定"我信什么"。
链：归属带来安全 → 群体有共同信念 → 反对信念 = 威胁归属 → 人会为了群体放弃事实。
关联：E2、E5

**C7 相对比绝对重要** `M`
人衡量自己过得好不好，看的是和周围人比，不是看绝对数字。
链：大脑擅长比较不擅长测量 → 参照物决定感受 → 同样的收入，换个圈子就从满足变焦虑。
关联：D2、E6

## D. 经济与资源

**D1 稀缺是一切价格的来源** `L`
不缺的东西没人付钱，缺的东西才有价。
链：想要的多于现有的 → 必须分配 → 价格是分配的工具 → 价格变化反映的是稀缺程度的变化。
关联：A1、D5

**D2 竞争把利润压向零** `S F`
有钱赚的地方会有人进来，进来的人多了就没钱赚了。
链：高利润 → 吸引进入者 → 供给增加 → 价格下降 → 利润回到平均 → 持续高利润一定靠某种壁垒。
关联：B4、D7、I

**D3 分工放大产出** `C G`
各做一件事，比每人什么都做，总产量高得多。
链：专注 → 熟练 → 效率高 → 交换 → 所有人都拿到更多 → 分工越细，对交换系统的依赖越深。
关联：B1、E3、F3

**D4 沉没成本不该算，但人总会算** `P C2`
已经花掉的钱回不来，却总在影响下一步。
链：投入越多 → 放弃越痛 → 继续投入 → 投入更多 → 更难放弃。
关联：B5、C2、A6

**D5 边际递减** `M`
第一口饭最香，第十口一般，第二十口反胃。
链：需求有限 → 多一单位的价值递减 → 到某点变负 → 资源应该往边际收益最高处挪，而不是往习惯处堆。
关联：B3、D1、E7

**D6 杠杆：放大好的也放大坏的** `F T`
借力能让小投入有大产出，但亏损时同样放大。
链：借入资源 → 收益倍增 → 亏损也倍增 → 超过承受点 → 强制平仓 → 杠杆的风险不在平均值，在极端值。
关联：A5、G3、G4

**D7 网络效应：越多人用越值钱** `F C G`
电话、语言、平台——用的人多，每个人得到的价值就更大。
链：用户多 → 对新用户更有价值 → 吸引更多用户 → 赢家通吃 → 后来者即使更好也难翻盘。
关联：D2、E2、F3

**D8 外部性：代价落在旁人身上** `I T`
工厂排污，利润归工厂，代价归下游。
链：行为的后果没有全部回到行为者 → 行为者做多了 → 总体受损 → 修正方法是把代价"内化"回去。
关联：C1、E4

## E. 组织与社会

**E1 制度是固化的激励** `C1 F P`
规则不是写在纸上的，是写在"做这件事会怎样"里的。
链：规则设定奖惩 → 人按奖惩行动 → 行动塑造文化 → 文化反过来守护规则 → 制度一旦成型极难改。
关联：C1、B1、P

**E2 规模改变性质** `A4 G`
十人的团队和千人的公司不是一回事，村庄和城市不是一回事。
链：人数增加 → 沟通路径按平方增加 → 需要层级和规则 → 灵活性下降 → 协调成本吃掉规模红利。
关联：A4、D3、E3

**E3 协调成本是组织的隐形税** `E L`
人越多，用来"对齐"的时间占比越高。
链：每个人都要知道别人在干什么 → 信息传递需要时间 → 信息会失真 → 组织大到一定程度，大部分精力花在内部而非外部。
关联：A2、D3、E2

**E4 公地悲剧** `D8 F`
公共的东西没人心疼，人人多拿一点，最后全完。
链：资源共享 → 每个人多拿的收益归自己、代价分给所有人 → 所有人都多拿 → 资源耗尽。
关联：C1、D8、B6

**E5 信念会自我实现** `F C4 C6`
大家相信银行要倒，一起去取钱，银行就真倒了。
链：预期 → 行动 → 行动改变现实 → 现实印证预期 → 社会系统里，"真假"常常取决于多少人信。
关联：A5、C4、C6、G4

**E6 地位是零和的** `C7 T`
财富可以一起增长，但"第一名"只有一个。
链：地位按相对排名 → 一人上升意味着另一人下降 → 地位竞争不会因富裕停止 → 这是很多冲突的真正来源。
关联：B3、C7

**E7 稳健的系统都有冗余和缓冲** `B6 E`
没有缓冲的系统效率最高，也最容易一次崩溃。
链：追求效率 → 削减备份 → 正常时更赚 → 意外时无缓冲 → 小问题连锁成大崩溃。
关联：B6、D5、G3

**E8 信任降低一切成本** `I E3`
信任是省下来的核查成本。
链：不信任 → 需要合同、监督、担保 → 每一步都加摩擦 → 信任建立慢、摧毁快 → 高信任社会的交易成本远低于低信任社会。
关联：E3、C6、P

## F. 信息与技术

**F1 地图不是疆域** `C4 I`
任何描述都是简化，简化就会丢东西。
链：现实太复杂 → 用模型代替 → 模型在某些情况下失效 → 把模型当现实 → 在失效点吃大亏。
关联：C4、G1

**F2 技术是叠上去的，不是换掉的** `P C`
新技术几乎总是站在旧技术的肩上，也继承旧技术的限制。
链：新东西依赖旧基础 → 旧基础的缺陷被带入 → 重写基础的代价极高 → 很多"不合理"其实是历史遗留。
关联：B5、P、A6

**F3 抽象让复杂可以堆叠** `G D3`
把细节包起来，只露接口，上一层就能不懂下一层地干活。
链：直接面对全部细节 → 人脑装不下 → 分层封装 → 每层只管自己 → 系统能无限加高，但某一层坏了上面全塌。
关联：D3、E2、D7

**F4 信息会腐烂** `E`
没人更新的文档、过期的地址、失效的链接。信息和房间一样需要维护。
链：世界在变 → 描述世界的信息不自动跟着变 → 差距越来越大 → 信息的价值随时间衰减，除非持续投入。
关联：A2、F1

**F5 复制便宜，创造昂贵** `C D1`
数字时代，第一份的成本是全部成本，第二份几乎免费。
链：创造需要大量投入 → 复制几乎零成本 → 价格趋向零 → 价值转移到"稀缺的那部分"：注意力、信任、原创、渠道。
关联：D1、D2、D7

**F6 工具改变使用者** `F P`
你塑造工具，然后工具塑造你。
链：工具让某种行为更容易 → 那种行为增多 → 习惯和思维随之变化 → 人变成工具想要的样子 → 再去造下一代工具。
关联：B4、C5、C3

**F7 测量什么就得到什么（但不一定是你想要的）** `C1 F`
考试考什么，学生就学什么，不管那是不是真本事。
链：目标难以直接观察 → 用指标代替 → 人优化指标而非目标 → 指标和目标脱钩 → 指标越好，真实越差。
关联：C1、E1、F1

## G. 时间、概率与决策

**G1 大多数事情是随机加一点趋势** `F1`
短期看全是噪音，长期才露出方向。
链：单次结果受运气主导 → 从一次结果推规律是错的 → 样本够大才能看见趋势 → 耐心本质上是让样本变大。
关联：F1、C4、C

**G2 不可逆的决定要慢，可逆的要快** `T P`
门能再推开的话，推错了没关系；门会锁死的话，推之前想清楚。
链：决定分两类 → 可逆的试错成本低、拖延成本高 → 不可逆的相反 → 大多数人把两类搞混：小事犹豫，大事冲动。
关联：C2、P、G3

**G3 极端事件决定长期结果** `D6 E7`
一百次小赢抵不过一次归零。
链：收益可以累加 → 归零不能恢复 → 长期结果由"最坏那次"决定 → 先保证活着，再谈平均回报。
关联：D6、E7、B6

**G4 缓慢累积，突然爆发** `A5 C`
破产怎么发生的？先是慢慢的，然后是突然的。
链：压力在看不见处累积 → 表面稳定 → 到临界点 → 瞬间崩溃 → 人只在爆发时才注意到，但原因在很早以前。
关联：A5、E5、D6

**G5 时间是最大的杠杆** `C`
早一点开始的微小优势，在足够长的时间里会变成无法追赶的差距。
链：增长率相同 → 起点早者基数大 → 同样比例的增长绝对值更大 → 差距随时间指数扩大 → 时间无法购买，只能提前。
关联：C、D7、B1

**G6 机会成本是真正的成本** `T L`
做一件事的代价，不是花了多少，而是没做的那件最好的事。
链：时间和资源只有一份 → 选 A 等于放弃 B → 账面上看不到 B → 人系统性地低估"没做什么"的代价。
关联：D5、L、G2

**G7 简单规则 + 迭代 > 复杂计划** `G B1`
能应对复杂世界的，往往不是更复杂的计划，而是更简单的规则加上快速修正。
链：世界变化快 → 复杂计划假设多、失效快 → 简单规则适应面广 → 反复试错修正 → 修正速度比初始质量重要。
关联：B1、B5、G2
